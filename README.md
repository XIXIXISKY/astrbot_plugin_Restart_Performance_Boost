## 🤝 介绍

这是一个集 **手动指令重启、定时任务重启、内存监控重启、每日定时重置上下文、设备性能查询、指令重载所有插件** 于一体的 AstrBot 重启增强插件，用以解决Bot长时间运行带来的上下文过长导致LLM回复过慢和内存泄露问题，适合低内存设备或有内存限制需求的设备使用。

## 📦 安装

### 方法一：插件市场
- 在 AstrBot 插件市场搜索 `重启性能增强`，点击安装，耐心等待安装完成即可。

### 方法二：命令行安装
- 在 AstrBot 聊天界面发送以下指令，回车即可自动安装：

```
/plugin install https://github.com/XIXIXISKY/astrbot_plugin_Restart_Performance_Boost
```

### 方法三：后台面板安装
- 打开 AstrBot 管理面板 → 插件管理 → 从仓库安装，输入上面的 GitHub 仓库地址，点击安装即可。

## ⌨️ 使用说明

> 所有命令均为管理员指令，空参或格式不对时会给出用法提示。

| 命令 | 用法 | 说明 |

| 帮助 | `帮助` | 查看本插件的完整使用说明 |

| 定时重置 | 设值：`定时重置 <HH:MM>`<br>关闭：`定时重置 关` | 每日定时重置上下文，如 `定时重置 04:00` 每天凌晨 4 点重置 |
| 清空所有会话上下文 | `清空所有会话上下文` | 一键清空所有已登记会话的上下文 |
| 查看列表 | `查看列表` | 查看当前已登记的群聊 / 私聊会话 |
| 增加会话 | 群聊：`增加会话 群聊 <群号>`<br>私聊：`增加会话 私聊 <QQ号>` | 把会话加入定时重置名单 |

| 内存阈值 | 设值：`内存阈值 <数值[单位]>`<br>开关：`内存阈值 开 / 关`<br>状态：`内存阈值 状态` | 设置内存阈值，如 `内存阈值 85` 或 `内存阈值 2048 mb` |
| 内存单位 | 设值：`内存单位 <percent>` 或 `内存单位 <mb>`<br>状态：`内存单位 状态` | 设置默认内存单位，只输数字时按该单位解释 |
| 内存监控 | 设值：`内存监控 <数值[单位]>`<br>开关：`内存监控 开 / 关`<br>状态：`内存监控 状态` | 设置阈值并同时开启内存监控，一条指令搞定 |

| 重载 | `重载 <插件名/序号>` | 重载插件，支持名称部分匹配，`重载 all` 重载全部插件 |
| 插件状态 | `插件状态` | 查看重启插件当前的完整配置状态 |
| 性能 | `性能` | 查看系统 CPU 和内存占用 |

| 余额 所有 | `余额 所有` | 查询所有已配置模型的余额 |

| 余额 json | `余额 json {"api_url":"…","api_key":"…"}` | 粘贴 NEW API 连接信息 JSON 查询 |

## ⚙️ 配置项

| 配置项 | 说明 | 默认值 |
| :--- | :--- | :--- |
| auto_restart_interval_seconds | 自动重启间隔（秒），0 为关闭 | 0 |
| show_memory_info | 重启完成后显示内存使用情况 | true |
| memory_monitor_enabled | 是否启用内存阈值监控自动重启 | true |
| memory_threshold_value | 内存阈值数值（支持小数） | 80 |
| memory_threshold_unit | 内存阈值单位：percent / mb | percent |
| memory_check_interval | 内存检查频率（秒） | 30 |
| memory_cooldown_seconds | 内存触发重启后的冷却时间（秒） | 600 |
| ctx_reset_time | 每日定时重置上下文时间（HH:MM，留空关闭） | 空 |

## ✅ 注意事项

- 本插件基于 AstrBot v4.27.2+ 开发，旧版本可能无法正常工作。
- 除「帮助」命令外，其余命令均为管理员指令，管理员需在 AstrBot 配置文件（`astrbot_config.json`）的 `admins` 字段中添加对应的 QQ 号。
- 内存监控触发重启后存在冷却时间，避免短时间内反复重启。
